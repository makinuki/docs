The `@makinuki/runtime-web` package is the browser runtime for MakiNuki WASM scraper plugins. It loads a registry of sources, verifies each `.wasm` binary against a SHA-256 checksum, and executes plugins via Extism with host functions provided under the `makinuki` namespace. The runtime requires WebAssembly JSPI (available in Chromium 123+) and ships with zero runtime dependencies beyond Extism.

## What the runtime does

When you create a `MakiNukiRuntime`, it wires together four layers:

1. **Registry** (`Registry`) fetches the public manifest at `https://makinuki.github.io/index.json` (or any custom URL) and caches it. Each entry carries the plugin metadata, download URL, and SHA-256 digest.
2. **Transport** (`TransportManager`) selects the best available network path. It can pin `direct`, `companion`, or `worker`, or auto-detect in that order.
3. **Plugin loader** (`MakiNukiPlugin`) instantiates the WASM binary through Extism and wires the four `makinuki:*` host functions.
4. **Source wrapper** (`MakiNukiSource`) exposes a typed JavaScript API around the raw plugin exports (`search`, `get_details`, `get_pages`, `get_metadata`, `get_filters`).

## Requirements

- A Chromium-based browser with JSPI support: Chrome 123+, Edge 123+, or Chrome for Android.
- No polyfills or bundler plugins are required. The package is an ES module with a single default export.
