The `makinuki/sources` repository is the official collection of reference source plugins for the MakiNuki manga reader stack. Each plugin is built with the [Plugin Development Kit](/pdk/introduction), compiled to a sandboxed WASM module, and published to the public registry. You can use these plugins as-is, study them as working examples, or fork them to create your own sources.

## Repository layout

```text
sources/
├── sources/
│   ├── asurascans/
│   ├── atsumaru/
│   ├── batcave/
│   ├── cubari/
│   ├── kagane/
│   ├── mangaball/
│   ├── mangadex/
│   ├── mangadotnet/
│   ├── mangafire/
│   ├── mangakakalot/
│   ├── omegascans/
│   └── weebcentral/
├── scripts/
│   ├── build.ts      # batch compiler: sources/* -> dist/*.wasm
│   └── release.sh    # per-plugin release script
├── dist/             # compiled .wasm outputs (gitignored)
└── package.json
```

Every subdirectory under `sources/` is one independent plugin package with its own `package.json`, `src/index.ts` entry point, `CHANGELOG.md`, and optional `test.json` fixture.

## Shipped reference sources

| Plugin | Approach | Notes |
| --- | --- | --- |
| `asurascans` | REST API | Asura Scans API with per-series chapter pagination |
| `atsumaru` | HTML scraping | Atsumaru reader with DOM parsing |
| `batcave` | HTML scraping | Gated by anti-bot challenge (`challengeGated: true`) |
| `cubari` | Aggregator | Multi-host aggregator with `allowedHosts` spanning dozens of CDNs |
| `kagane` | HTML scraping | Multi-language source with rotating domains |
| `mangaball` | HTML scraping | Simple manga reader scraper |
| `mangadex` | REST API | MangaDex official API with cover size variants and blocked-group filtering |
| `mangadotnet` | HTML scraping | Manga reader site scraper |
| `mangafire` | HTML scraping | Gated by anti-bot challenge |
| `mangakakalot` | HTML scraping | Classic manga reader scraper |
| `omegascans` | HTML scraping | Omega Scans reader |
| `weebcentral` | HTML scraping | Gated by anti-bot challenge |
