MakiDoku exposes a local REST API on `http://127.0.0.1:6254`. The base path is `/api`. All responses use JSON. Errors follow the standard MakiNuki envelope:

```json
{"error": {"code": "...", "message": "..."}}
```

## Health

| Method | Path | Description |
| --- | --- | --- |
| `GET` | `/api/health` | Daemon health, version, commit, and database status |

## Sources

| Method | Path | Description |
| --- | --- | --- |
| `GET` | `/api/sources` | List installed sources |
| `GET` | `/api/sources/catalog` | View registry catalog with local state |
| `POST` | `/api/sources/install` | Install from catalog id or local path |
| `POST` | `/api/sources/update-all` | Update all compatible sources |
| `GET` | `/api/sources/{id}` | Get one installed source |
| `PATCH` | `/api/sources/{id}` | Update source metadata (e.g. pinned) |
| `DELETE` | `/api/sources/{id}` | Uninstall a source |
| `GET` | `/api/sources/{id}/icon` | Fetch cached source icon |
| `POST` | `/api/sources/{id}/update` | Update one source to latest |
| `GET` | `/api/sources/{id}/filters` | List source browse filters |
| `GET` | `/api/sources/{id}/search` | Search source (`?q=&page=&filters=`) |
| `POST` | `/api/sources/{id}/clearance` | Submit anti-bot clearance |

## Downloads

| Method | Path | Description |
| --- | --- | --- |
| `GET` | `/api/download` | Queue snapshot with stats and downloader `paused` flag |
| `POST` | `/api/download` | Enqueue chapters for download |
| `POST` | `/api/download/pause-all` | Pause the downloader; workers stop claiming and the in-flight row is returned to the queue |
| `POST` | `/api/download/resume-all` | Resume the downloader |
| `POST` | `/api/download/cancel-all` | Cancel every active queue row |
| `POST` | `/api/download/cancel` | Cancel the listed queue items (body: `{"itemIds":[...]}`) |
| `POST` | `/api/download/reorder` | Store queue order given as item ids in display order (body: `{"itemIds":[...]}`) |
| `GET` | `/api/download/events` | WebSocket: real-time events |
| `POST` | `/api/download/{itemID}/pause` | Pause item |
| `POST` | `/api/download/{itemID}/resume` | Resume item |
| `POST` | `/api/download/{itemID}/cancel` | Cancel item |
| `POST` | `/api/download/{itemID}/retry` | Retry failed item |
