MakiNuki (巻抜き) is a cross-platform open source stack for reading manga and webtoons. Sources ship as sandboxed WebAssembly plugins that conform to a frozen ABI, and every host runtime (browser, Go daemon, embedded reader) speaks the same contract. This site documents each repository in the [`makinuki` organization](https://github.com/makinuki) and how they fit together.

## How the pieces fit

<Steps>
  <Step title="A source is authored">
    A scraper is written against the [ABI](/spec/introduction) using the [PDK](/pdk/introduction) and compiled to a single `.wasm` binary.
  </Step>
  <Step title="It is published to the registry">
    The plugin ships to the [source registry](/sources/registry/overview) at `https://makinuki.github.io/index.json` with a SHA-256 digest.
  </Step>
  <Step title="A host loads and runs it">
    Any host that speaks ABI 1 loads the plugin, verifies its digest, and invokes exports through host-managed I/O: the [web runtime](/runtime/introduction) in a browser, or [MakiDoku](/makidoku/introduction) on desktop.
  </Step>
  <Step title="A reader renders the pages">
    Rendered pages flow into a UI, such as the [Mekuri](/mekuri/introduction) engine embedded in a web reader or the React SPA shipped by MakiDoku.
  </Step>
</Steps>
