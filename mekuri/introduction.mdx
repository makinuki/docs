Mekuri is a headless-first reader engine and view library for manga, comics, and webtoons on the web. It lets you build custom readers without fighting opinionated markup, while still offering optional prebuilt views when you want to ship fast.

The library is split into three surfaces:

- **`engine`**: headless state machine, pure page math, keyboard and tap-zone registries, gesture state, and virtualization math. No DOM and no CSS.
- **`views`**: optional unstyled, themeable view implementations and HUD primitives driven by CSS custom properties.
- **`test-utils`**: gesture simulators, viewport mocks, and observer mocks for testing host integrations under JSDOM.

Mekuri is currently pre-release. It requires React and React DOM 18.2 or 19 as peer dependencies. The only runtime dependency is `@tanstack/react-virtual`, and only the continuous views load it.
