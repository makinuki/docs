MakiNuki is split into small, independently versioned packages. Each project owns one concern and stays replaceable.

## How they fit together

A MakiNuki-based reader typically combines:

- **A source plugin** built with the [PDK](/pdk/introduction). The plugin runs in a WebAssembly sandbox and implements the MakiNuki ABI: metadata, filters, search, details, pages, and optional image unscrambling.
- **A host application** that loads the plugin, fetches images, handles authentication, and persists reading position.
- **A reader surface** built with [Mekuri](/mekuri/introduction). The engine owns reading state, spreads, gestures, keyboard, and the failure registry; the host owns the DOM and the network.
